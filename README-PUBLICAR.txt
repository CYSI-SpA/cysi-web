PUBLICAR GRATIS EN CLOUDFLARE PAGES
1. Crear un repositorio en GitHub, por ejemplo: cysi-web.
2. Subir el contenido de esta carpeta a la raíz del repositorio.
3. Entrar a Cloudflare > Workers & Pages > Create > Pages > Connect to Git.
4. Elegir el repositorio.
5. Framework preset: None.
6. Build command: dejar vacío.
7. Build output directory: / (raíz).
8. Deploy.

Luego se puede conectar un dominio propio .cl sin cambiar el código.
